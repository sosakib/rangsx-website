## What it is
A static rebuild of beta.rangsx.com, the site of RangsX, the EV business unit of Rangs Group in Bangladesh
(Dongfeng electric vans and microbus, RX electric bikes, RX Gear accessories). Zero dependencies: a Node build
writes plain HTML/CSS/JS to `dist/`. No framework, no npm install. Every page also exists in Bangla at `/bn/...`.

- Repo: https://github.com/sosakib/rangsx-website (public). Work on `homepage-intro`; after each commit,
  fast-forward `main` with `git branch -f main HEAD`.
- Live preview: https://sosakib.github.io/rangsx-website/ (GitHub Pages serves the `gh-pages` branch).
- Production will be https://rangsx.com (`SITE.url`). Not live there yet.

## Commands
```bash
node site/build.mjs                                          # build dist/ + checks (links, one h1, no dashes, Bangla)
node serve.mjs --port 4500 --no-open --no-build              # serve dist/ (supports byte ranges for the video)
./deploy-pages.sh                                            # build with BASE=/rangsx-website, push dist/ to gh-pages
```
`start.bat` / `start.sh` build, serve and open a browser. Node 20+ (this PC has 24).

A build that prints anything under "Checks:" is not done. "strings have no Bangla yet" means: add the strings
listed in `site/i18n/missing.txt` to the right `site/i18n/bn-*.mjs`, then build again.

## How the pieces work
- **Bangla:** the build renders each page in English, then `toBangla()` (site/lib/i18n.mjs) translates its text
  through the dictionaries and records anything missing. Strings written by client JS use `T(en, bn)`, keyed on `<html lang>`.
- **Paths:** source uses root paths (`/shop`, `/img/...`). For GitHub Pages the build rewrites them to
  `/rangsx-website/...` when `BASE` is set. In client JS, keep the language prefix in ONE string literal,
  `(BN ? "/bn/" : "/")`, so the rewrite covers both languages; never write `(BN ? "/bn" : "") + "/x"`.
- **Account, basket, orders (demo):** everything is in `localStorage` (`rx-account` = profile, cart, orders, ship;
  `rx-session` = signed in). Sign-in (Google) and payment (SSLCOMMERZ dialog) are simulated and clearly marked.
  `BACKEND.md` says what replaces each piece. The server must recompute every price.
- **Checkout:** Basket -> Details -> Payment -> done. Sign-in required before Details. RX Gear is paid in full;
  an RX bike is booked with `SITE.bikeBooking` (Tk 10,000, confirmed), balance before handover. Delivery is free
  (confirmed); home delivery or showroom pickup, for bikes too (confirmed 5 Oct 2026).
- **Homepage film:** `<video>` scrubbed by scroll. It streams with byte ranges; a 2-byte range probe falls back
  to download-then-scrub on hosts without ranges. Reduced motion gets a static version.
- **Chat:** the corner button opens a WhatsApp-style chat window (demo) that hands off to wa.me.

## Rules (from the client and the user)
- Never invent specs, prices or facts: take them from `site/data` or `_research`. RX bike retail prices are
  CONFIDENTIAL: never on the site, never in this public repo.
- Ponytail style: the smallest change that works, reuse what exists, no new dependencies.
- House style: no en or em dashes in visible text (the build checks), one `<h1>` per page, red #ED2328 only for
  accents, glows grey in the light theme, WCAG 2.2 AA, `prefers-reduced-motion` gets a static version.
- Brand: Lemon Milk headlines (licence confirmed), Poppins text, Li Ador Noirrit for Bangla; black, white, grey
  #BCBEC0, red. Header 80 px (64 px on phones). Taglines and model names stay English on Bangla pages.
- Commit after each round with the trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Push and
  deploy only when the user asks ("push it to GitHub"). Add a round to `progress.md` every time: what changed,
  what was verified, what is open.

## Gotchas on this Windows PC (Git Bash)
- A background server dies after about 10 minutes. Start it in the same command as the test:
  `(node serve.mjs --port 4600 --no-open --no-build > /dev/null 2>&1 &); sleep 2; node test.mjs`
- Prefix commands that pass `/paths` with `MSYS_NO_PATHCONV=1` (BASE included), or Git Bash rewrites them to
  `C:/Program Files/Git/...`. `deploy-pages.sh` already does.
- Heredocs with quotes or backticks often break: write files with an editor tool, then run them.
- No ffmpeg on PATH: use imageio_ffmpeg's binary (`.../site-packages/imageio_ffmpeg/binaries/ffmpeg-win-x86_64-v7.1.exe`).
- This PC's GitHub login lacks the `workflow` scope, so pushing `.github/workflows/*` is refused. That is why
  deploys go through `deploy-pages.sh` instead of Actions.

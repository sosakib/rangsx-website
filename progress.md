# RangsX website redesign — progress

Source: https://beta.rangsx.com (Next.js). Target: static, fast, SEO-clean rebuild with the **same page tree and
the same per-page layouts** as the beta, with calmer, more premium visuals, motion and interaction.
Stack: zero-dependency Node build (`node site/build.mjs`) → `dist/`. Vanilla CSS + JS. Self-hosted fonts.
